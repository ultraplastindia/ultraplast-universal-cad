# Reference data used for the table-top chain size presets (v1.0.1)

The "Modular chain / belt" family has 7 ready sizes (ids `MB-REF-*`) and the catalogue items *Tabletop, Flat-top and Plastic conveyor chains* start from size class A. These sizes are the **basic published dimensions** (pitch, chain width, rod diameter, plate or height values) of 38.1 mm (1.5 in) pitch table-top plastic chains as listed in public product data sheets. Only numbers were used. No drawings, images, CAD files or proprietary geometry were copied.

| Class | Pitch | Widths (mm) | Rod dia | Thickness used |
|---|---|---|---|---|
| A (820-type) | 38.1 | 82.6, 101.6, 114.3, 152.4, 190.5 | 6.4 | 10.4 (listed "plate bottom to chain bottom") |
| B (828 / 879-type) | 38.1 | 82.5/82.6, 114.3 | 7.1 | 11.2 (listed for the 828 data sheet) |
| C (882-type) | 38.1 | 82.6, 114.3, 190.5, 254, 304.8 | 8.6 | 13.8 (estimated: height over centreline + half the rod) |

Sources (read on 14 Nov 2026): Rexnord 820, 879 and 882 Series TableTop Chain product portfolios (documents.mrosupply.com) and the System Plast 828 data sheet (docs.rs-online.com).

Important:
- These are **reference size classes**, not Ultraplast products. The thickness values mix different listed dimensions (see the table), so they are approximate. Check every value against your own chain data sheet or drawing before use.
- Sprocket data in those sources was not used (it could not be read reliably).
- The shape is still the generic module: no knuckles, tabs or tooth pockets.
- If you supply Ultraplast's own series table (pitch, width, thickness, rod diameter), replace these presets with it.
